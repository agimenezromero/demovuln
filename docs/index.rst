demovuln
========

``demovuln`` is a Python package for simulating temporally structured
demographic perturbations in matrix population models and estimating integrated
population vulnerability.

The package supports two complementary levels of analysis:

1. simulation of individual perturbation trajectories;
2. evaluation of perturbation grids and computation of integrated vulnerability.
